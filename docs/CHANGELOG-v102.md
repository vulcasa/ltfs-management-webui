# LTFS 磁带管理系统 v1.0.2 更新说明

**发布日期**: 2026-02-28  
**版本**: 1.0.2  
**代号**: File Browser Edition

---

## 新增功能

### 1. 文件浏览器

#### 双面板设计
- **左侧浏览器**: 浏览容器内 `/mnt` 目录
- **右侧浏览器**: 浏览磁带 `/media/tape` 目录
- **Finder 风格**: 现代化的列表视图界面

#### 导航功能
- **面包屑导航**: 显示当前路径，支持点击跳转任意层级
- **目录浏览**: 点击文件夹图标进入子目录
- **上级目录**: 支持通过 `..` 返回上级目录
- **刷新按钮**: 随时刷新两侧文件列表

#### 文件列表
- **图标显示**: 文件夹显示 📂，文件显示 📄
- **排序**: 目录在前，文件在后，按名称字母序排列
- **大小显示**: 友好的字节格式化显示（Bytes/KB/MB/GB/TB）
- **多选功能**: 
  - 单个文件选择
  - 全选/取消全选
  - 支持跨目录多选

### 2. 文件传输系统

#### 双向传输
- **容器 → 磁带**: 从本地容器传输到磁带存储
- **磁带 → 容器**: 从磁带传输到本地容器
- **智能方向**: 双向箭头按钮自动判断传输方向

#### 传输类型
- **复制模式**: 保留源文件，创建副本
- **移动模式**: 传输后删除源文件（剪切）
- **类型选择**: 下拉菜单快速切换

#### 进度监控
- **实时进度条**: 可视化显示传输进度
- **百分比显示**: 精确到小数点后一位
- **已传输/总大小**: 显示当前传输的字节数
- **当前文件**: 显示正在传输的文件名
- **平均速度**: 实时计算并显示传输速度（MB/s）

#### 自动刷新
- **2 秒轮询**: 自动刷新传输状态
- **状态更新**: 实时跟踪 pending → in_progress → completed/failed
- **任务列表**: 显示最近 50 个传输任务
- **错误信息**: 传输失败时显示详细错误

## 技术实现

### 后端 API
- `/file-browser` - 文件浏览器页面
- `/api/browser/list` - 获取目录列表
- `/api/transfer/start` - 启动传输任务
- `/api/transfer/status/<id>` - 获取单个任务状态
- `/api/transfer/list` - 获取传输任务列表
- `/api/transfer/cancel/<id>` - 取消传输任务

### 数据库模型
- **FileTransfer 表**: 完整的传输任务记录
  - 源路径、目标路径
  - 传输类型、传输方向
  - 进度、已传输大小、总大小
  - 文件数量、当前文件
  - 平均速度、错误信息
  - 创建时间、更新时间

### 文件传输管理器
- **后台线程**: 异步处理文件传输
- **进度跟踪**: 实时更新数据库
- **块级复制**: 1MB 块大小，避免内存溢出
- **异常处理**: 完善的错误捕获和记录
- **速度计算**: 基于传输时间和大小计算平均速度

## UI 优化

### 视觉设计
- **卡片式布局**: 左右两侧独立卡片
- **渐变侧边栏**: 保留原有蓝色渐变主题
- **圆角设计**: 12px 圆角，现代化视觉
- **状态标签**: 不同状态使用不同颜色

### 交互体验
- **按钮状态**: 未选择文件时传输按钮禁用
- **全选联动**: 全选框与单个复选框联动
- **路径安全**: 限制只能访问 /mnt 和 /media/tape
- **面包屑**: 点击任意路径节点快速跳转
